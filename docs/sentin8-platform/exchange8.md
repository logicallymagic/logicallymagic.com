# Exchange8

  <img src="/img/project-grid/exchange8.jpg" alt="Exchange8" />
</div>

Exchange8 is the capital markets vertical of the Sentin8 platform: a
deterministic matching engine with FIX/OUCH access, smart order routing,
clearing, margin, and multi-jurisdiction regulation.

## What it is

A venue-grade matching engine with deterministic semantics — the same
inputs always produce the same outputs, which is what regulators, auditors,
and HFT firms all demand.

## The business case

- **Operate a venue without building one.** Exchange8 provides the
  order-entry protocols, matching, clearing, and margin stack an operator
  needs — integrated with Sentin8's identity and audit plane.
- **Determinism is a market advantage.** A deterministic matching engine can
  be replayed exactly, which shortens incident investigations, satisfies
  regulators, and makes the promise of "fair, orderly markets" provable.
- **Multi-jurisdiction by design.** Rule packs per jurisdiction mean the
  same engine can operate across borders without forking code.
- **Institutional connectivity on day one.** FIX and OUCH support means
  sell-side and algorithmic clients integrate using the tools they already
  run.

## Core capabilities

| Capability | Why it matters |
| --- | --- |
| **Deterministic matching engine** | Replayable, auditable, and provably fair market behaviour. |
| **FIX / OUCH access** | Institutional and low-latency order entry without custom protocols. |
| **Smart order routing** | Route order flow to the venue with the best outcome. |
| **Clearing & margin** | Full post-trade lifecycle, including margining, inside one vertical. |
| **Multi-jurisdiction regulation** | Per-jurisdiction rule packs instead of code forks. |

## Who it's for

- **Market operators and ECNs** launching a regulated or alternative venue.
- **Brokers and market makers** that need an internal crossing engine.
- **Investment banks** modernizing legacy matching infrastructure.
