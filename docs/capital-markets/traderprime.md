# traderPRIME

<div className="doc-image-frame">
  <img src="/img/project-grid/trader-thumb.jpg" alt="traderPRIME" />
</div>

traderPRIME is a suite of products providing a cross-asset trading platform
and execution management system designed with an engaging GUI and a
super-fast API for both human and algorithmic trading — in C++, C#, Java,
Python, R, JavaScript, VB, and shell scripts. It runs on all currently
available operating systems (Apple/iOS, Windows, Linux, Android) and
hardware architectures (Intel/ARM, 64-bit/32-bit).

## The business case

- **One platform, every asset class.** Cross-asset support means desks stop
  maintaining one terminal per market and one reconciliation process per
  terminal.
- **Your quant team keeps its language.** Super-fast native APIs across
  C++, C#, Java, Python, R, and more mean strategies ship from research to
  production without translation.
- **Excel is a trading terminal.** With MegaEX, traders who live in Excel
  get real-time data and execution natively — no export/import cycle, no
  stale numbers.
- **ML in a spreadsheet cell.** With MegaAI, machine learning models become
  as easy as any native Excel function — research happens where the
  business already works.

## The Mega suite

### MegaDT — market data processing

A market data processing system that can handle high data volumes at ultra
low latencies is critical to trading. Such systems play an essential role in
algorithmic trading, risk analysis, market surveillance, and many other
related areas. NYSE and NASDAQ alone generate over 40,000,000,000 messages
per trading hour (6 TB per hour). To process such a high volume of data in
sub-microseconds requires very unique development practices and
architecture — these are the foundations of MegaDT.

### Trader GUI

The graphical user interface has been especially designed for platforms
where screen real estate matters. It allows the application to take over
window management — toolbars, grips, headers, buttons, and areas that would
otherwise be wasted. Rearranging many windows is as easy as the click of a
button.

### MegaEX — real-time algorithmic trading for Excel

MegaEX is a native Excel plugin and provides real-time algorithmic trading
for Excel. In combination with MegaDT, it supplies full trading capabilities
(real-time data and execution) for Excel — enabling the trader to operate
fully from Excel while taking advantage of Excel's feature-rich functions
and charts.

### MegaAI — machine learning as an Excel function

In conjunction with MegaAI, one can use all machine learning algorithms as
easily as any other Excel native function. The machine learning framework
includes:

- **Classification**: Support Vector Machines, Neural Networks, Deep
  Learning…
- **Clustering**: K-Means, K-Modes, Mean-Shift, Gaussian Mixture Models…
- **Regression**: Multiple linear regression, Multivariate linear
  regression…
- **Distributions**: Parametric and non-parametric estimation, Univariate
  distributions…
- **Kernel algorithms**: Kernel Support Vector Machines, Multi-class and
  multi-label machines, Sequential Minimal Optimization…
