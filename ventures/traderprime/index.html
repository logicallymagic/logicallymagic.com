• traderPRIME

    AI-Assisted Ultra-Low-Latency Cross-Asset Trading Platform

traderPRIME is a suite of products providing a cross-asset trading platform and execution management system designed with an engaging GUI and super-fast API for both human and algorithmic trading in C++, C#, JAVA, Python, R, JAVA Scripts, VB, and Shell scripts. It runs on all currently available operating systems (Apple/iOS, Windows, Linux, and Android) and hardware architects (Intel/ARM - 64bit/32bit).

A market data processing system that can handle high data volumes at ultra low latencies is critical to trading. Such systems play an essential role in algorithmic trading, risk analysis, market surveillance, and many other related areas. NYSE and NASDAQ alone generate over 40,000,000,000 messages per trading hours (6TB per hour). To process such high volume of data in sub-microseconds requires a very unique development practices and architecture, which are the foundations of MegaDT.

The graphical user interface (GUI) has been especially designed for platforms that screen real estate matters. It allows the application to take over window management toolbars, grips, headers, buttons, and areas that would otherwise be wasted and not used. It also makes the handling and rearranging of many windows as easy as the click of a button.

MegaEX is a native Excel plugin and provides real-time algorithmic trading for Excel. In combination with MegaDT, it supplies full trading capabilities (real-time data and execution) for Excel, thus enabling the trader to operate fully from Excel while taking advantage of Excel's feature-rich functions and charts.

Furthermore, in conjunction with MegaAI, one can use all machine learning algorithms as easily as using any other Excel native function. Machine learning framework includes:

  • Classification: Support Vector Machines, Neural Networks, Deep Learning ...
  • Clustering: K-Means, K-Modes Mean-Shift, Gaussian Mixture Models ...
  • Regression: Multiple linear regression, Multivariate linear regression ...
  • Distributions: Parametric and non-parametric estimation, Univariate distributions ...
  • Kernel Algorithms: Kernel Support Vector Machines, Multi-class and Multi-label machines, Sequential Minimal Optimization ...
